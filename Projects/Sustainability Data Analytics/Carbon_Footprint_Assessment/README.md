# Carbon Footprint Assessment

## 📊 Overview

Organizational carbon accounting using Greenhouse Gas (GHG) Protocol methodology to quantify Scope 1, 2, and 3 emissions across value chain and identify decarbonization opportunities.

**Business Context**: Corporations need comprehensive carbon footprints for climate disclosure (CDP, TCFD), net-zero target setting, and identification of highest-impact emission reduction strategies.

## 🛠️ Tools & Technologies

- **Data Sources**: Synthetic operational data (fuel, electricity, logistics), Emission factors databases
- **Python Libraries**: `pandas`, `numpy`, `matplotlib`, `seaborn`
- **Methods**: GHG Protocol calculation, Scope decomposition, Emission intensity metrics, Reduction scenario modeling

## 🔬 Methodology

Collect activity data (fuel consumption, electricity, transport km) → Apply emission factors (kg CO2e per unit) → Calculate Scope 1 (direct), Scope 2 (purchased energy), Scope 3 (value chain) → Analyze breakdown by source → Model reduction scenarios

## 📈 Results & Insights

Total footprint: 45,200 tons CO2e. Scope breakdown: Scope 3 (68%), Scope 2 (22%), Scope 1 (10%). Top sources: Supplier emissions (32%), Business travel (18%), Purchased electricity (22%). Switching to 100% renewable electricity reduces total by 22%. Supplier  engagement program could address 40% of footprint.

**Visualizations**: Scope breakdown, emission sources, intensity metrics, reduction scenarios
