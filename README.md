# 🌍 Damilola's Data Science, Sustainability & Geospatial Portfolio

Welcome to my professional portfolio! This repository showcases **41 advanced data science and geospatial analysis projects** demonstrating expertise in Earth Engine, Sustainability Analytics, and Machine Learning.

## 📂 Repository Structure

The portfolio is organized into three specialized domains under the `Projects/` directory:

```
Damilola-Portfolio/
├── Projects/
│   ├── GIS analytics/                  # 17 Geospatial & Remote Sensing Projects
│   ├── Sustainability Data Analytics/  # 12 ESG & Environmental Analytics Projects
│   └── Data analytics/                 # 12 Business Intelligence & ML Projects
└── README.md                           # This navigation guide
```

Each project folder is self-contained and follows a standard professional structure:
- **`README.md`**: Detailed project overview, methodology, and key insights.
- **`analysis.ipynb`**: The core Jupyter Notebook containing the code and analysis.
- **`outputs/`**: A dedicated folder containing all generated maps, charts, and visualizations.

## 📖 How to Use This Portfolio

1.  **Browse**: Click on any project link above to view its detailed `README.md`.
2.  **Explore**: Open the `analysis.ipynb` in any project to see the code and methodology.
3.  **View Results**: Check the `outputs/` folder in each project for high-quality maps and charts.

### Prerequisites
To run the geospatial notebooks, you will need a Google Earth Engine account and authentication:
```bash
earthengine authenticate
```
